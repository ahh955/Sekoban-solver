A push-optimal Sokoban solver: it splits each level into its rooms and solves each room with push-based A* (Hungarian assignment heuristic, dead-square and frozen 2x2 pruning). Practice score 1,000,000 — all 5 instances in P* pushes.

Run: `MAKEFUN_INPUT_DIR=<input> MAKEFUN_OUTPUT_DIR=<output> node main.ts`
